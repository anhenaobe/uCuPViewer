## Reglas para el cierre

- No confundir **tarea asignada** con **tarea terminada**.
- Enlazar commits, PR, archivos o resultados que permitan inspeccionar cada aporte.
- Identificar colaboraciones entre integrantes sin atribuirlas a una sola persona.
- Para pruebas, registrar quién las ejecutó, qué versión se ensayó y dónde está la evidencia.
- Las herramientas de IA se registran por separado en [Uso de IA](USO_IA.md).
- El equipo revisa este registro antes de marcar la verificación de aportes como cumplida.
